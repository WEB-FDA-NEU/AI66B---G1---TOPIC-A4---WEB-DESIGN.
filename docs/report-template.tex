\fillin{Overview}

\textbf{What changed since Milestone 2:} \fillin{real backend, database, login, \ldots;
screens dropped or merged and why}

\begin{example}
ReLoop lets students sell used items to other students on the same campus. A seller posts a
listing with photos and a price; a buyer searches by category and price, and must log in to see
the seller's phone number. The core flow is \emph{search $\to$ listing detail $\to$ reveal phone}.

\textbf{Since M2:} all pages now read from our FastAPI backend instead of \cpath{mock/*.json};
login and register work with real accounts; the ``Saved items'' screen was dropped (P1).
\end{example}

\begin{example}
\begin{lstlisting}
Browser: frontend/*.html + js/pages/*.js
   |  api.js: fetch('/api/listings?category=books', { Authorization: 'Bearer <token>' })
   v
FastAPI: main.py -> routers/listings.py -> Depends(get_session), Depends(get_current_user)
   |  SQLModel: select(Listing).where(Listing.category_id == 3)
   v
SQLite: app.db  (tables user, category, listing)
\end{lstlisting}
FastAPI serves the frontend with \code{app.mount("/", StaticFiles(directory="frontend", html=True))},
placed after all routers, so the browser and the API share one origin and no CORS is needed.
\end{example}
